# TuPrimeraPagina-Strada
Petra Makeup Store fue desarrollada utilizando Python y Django como framework principal. Primero se creó un entorno virtual. Después se creó el proyecto principal llamado “Marca” y las aplicaciones “petra” y “accounts”.
En la aplicación “petra” se desarrollaron las secciones principales de la página, como inicio, productos, reseñas e historia de la marca. En “accounts” se desarrollo todo lo que es relacionado con el usuario y con perfil, tanto inicio de sesion,registro, editar y ademas de instalo pillow para el tema de uso de imagenes en el perfil.
Luego en los templates de cada aplicacion se trabajo el tema de lo que el usuario ve en la pagina, en los models se definio bien que puede hacer el usuario dentro de la pagina (se uso migraciones para pasar todo a la base de datos)y en views se termino de desarrollar las funciones que puede hacer el usuario
Y finalmente se creó un superusuario para administrar el sitio desde el panel de Django Admin y se ejecutó el servidor local para probar el funcionamiento completo de la página.
